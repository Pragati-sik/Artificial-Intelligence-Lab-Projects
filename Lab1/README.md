\# Smart Irrigation Decision System



\## About the Project

The Smart Irrigation Decision System is a Python-based

expert system that recommends irrigation levels based on

environmental conditions and crop requirements.



\## Features

\- Soil moisture input

\- Temperature monitoring

\- Humidity input

\- Rainfall input

\- Two crop types: Rice and Wheat

\- Rule-based irrigation decisions

\- Exception handling

\- Input validation



\## Technologies Used

\- Python

\- Git

\- GitHub



\## Irrigation Recommendations

\- No Irrigation

\- Low Irrigation

\- Medium Irrigation

\- High Irrigation







\## Concepts Used

\- Expert Systems

\- Facts and Rules

\- Conditional Statements

\- Functions

\- Exception Handling
